# Barbearia Elite 💈

> A modern, responsive website for a barbershop, built with HTML, CSS and JavaScript.

[🌐 **Live Demo**](https://barbeariakercha.vercel.app/)

## ✨ Features

* 📱 Responsive, mobile-first design
* 💈 Modern barbershop landing page
* ✂️ Services section
* 🖼️ Image gallery
* 💬 Customer testimonials
* 📍 Google Maps integration
* 📱 WhatsApp integration
* 📧 Contact section
* 🔎 Basic SEO optimization

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

## 📂 Project Structure

```text
barbearia-site/
├── css/
├── image/
├── js/
├── favicon.svg
├── index.html
└── README.md
```

## 🎯 Purpose

This project was created to practice building a complete website for a real-world local business.

The goal was to combine a responsive interface with practical features that a real barbershop could use to showcase its services and make it easier for customers to get in touch.
